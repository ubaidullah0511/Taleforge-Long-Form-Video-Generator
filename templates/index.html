B-Roll Retrieval System

Two pipelines: per-scene B-roll matching (/process-script) and the full documentary visual research pipeline (/generate-documentary-timeline).

1. Script Input
→
2. Table Generation (LLM)
→
3. Asset Search (7 providers)
→
4. Scoring & Dedup
→
5. Download
→
6. Timeline Output

Process Script (one best clip per scene)

Splits the script into scenes and picks the single best-matching clip for each, from the local library or Pexels/Pixabay.

Generate Documentary Timeline (full research pipeline)

Runs all 6 pipeline stages above: table generation, multi-provider search, scoring, dedup, parallel download, and timeline/table output on disk.
